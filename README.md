# 高額療養費 限度額・多数回該当計算ツール

高額療養費制度について、年齢・所得区分・診療月・総医療費・自己負担額・過去12か月の該当履歴から、月額自己負担限度額と多数回該当の可能性を計算するPWAです。

## 対応制度

**2026年8月診療分～2027年7月診療分**を基準に実装しています。

- 70歳未満：区分ア・イ・ウ・エ・オ
- 70～74歳：現役並みⅢ・Ⅱ・Ⅰ、一般、低所得Ⅱ・Ⅰ
- 75歳以上：後期高齢者医療制度の現役並みⅢ・Ⅱ・Ⅰ、一般Ⅱ・Ⅰ、低所得Ⅱ・Ⅰ
- 通常の月額自己負担限度額
- 多数回該当時の自己負担限度額
- 2026年8月からの年間上限額の表示
- 70歳以上の外来（個人）／外来＋入院（世帯）の区別

## 主な計算機能

### 1. 月額限度額
総医療費（保険診療10割）を入力すると、所得区分に応じた「＋1%」を含む限度額を自動計算します。

### 2. 自己負担額の判定
実際の自己負担額、または医療機関等ごとの自己負担額から、今回の高額療養費該当可能性を判定します。

70歳未満では、原則として1医療機関等あたり21,000円以上の自己負担のみを世帯合算対象として計算します。

### 3. 多数回該当
療養月以前の直近12か月について、高額療養費に該当した月を入力すると、今回が4回目以降となるかを判定します。

70～74歳および75歳以上では、外来限度額だけで高額療養費となった月を多数回該当のカウントから除外できる仕様です。

### 4. 世帯合算
世帯合算後の自己負担額を入力できます。医療機関等の入力欄を利用すると、70歳未満の21,000円基準による合算対象額も確認できます。

## 2026年8月～2027年7月の主な限度額

### 70歳未満

| 区分 | 通常の月額限度額 | 多数回該当 |
|---|---:|---:|
| ア | 270,300円＋(総医療費－901,000円)×1% | 140,100円 |
| イ | 179,100円＋(総医療費－597,000円)×1% | 93,000円 |
| ウ | 85,800円＋(総医療費－286,000円)×1% | 44,400円 |
| エ | 61,500円 | 44,400円 |
| オ | 36,900円 | 24,600円 |

### 70歳以上・75歳以上

現役並み所得者の月額限度額は70歳未満の区分ア～ウと同じです。

## 重要な注意

- 多数回該当は原則として、直近12か月に3回以上高額療養費に該当し、4回目以降となる場合に適用されます。
- 限度額適用認定等により自己負担限度額までの支払いとなった月も、多数回該当の判定対象になります。
- 保険者が変更された場合、原則として月数を通算できません。
- 70～74歳では、外来限度額だけで高額療養費となった月は多数回該当の回数に含めません。
- 70歳未満の21,000円基準による世帯合算には、医療機関・医科/歯科・入院/外来等の区分があります。薬局の自己負担は原則として処方せんを発行した医療機関分に合算して扱います。
- 2026年8月から年間上限が新設されていますが、本ツールは年間の精算額を確定するものではありません。
- 2027年8月からは所得区分がさらに細分化されるため、将来の診療月については別途更新が必要です。
