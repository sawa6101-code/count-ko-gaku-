# 多数回該当判定ツール（count-ko-gaku-）

高額療養費制度における「多数回該当」に該当する可能性を簡易判定するPWAです。

## 主な機能

- 年齢区分を入力して判定
  - 70歳未満
  - 70～74歳
  - 75歳以上
- 判定対象月を設定
- 直近12か月の高額療養費該当月を月単位で入力
- 現在の月が高額療養費に該当する場合を含めて判定
- 保険者が同一かどうかを確認
- 70～74歳の外来のみの該当月について注意喚起
- 多数回該当（過去12か月以内に3回以上該当し、4回目以降となる場合）の可能性を表示
- 入力内容を端末内に保存
- PWA対応・オフライン利用対応

## 多数回該当について

原則として、直近12か月間に高額療養費に該当した月が3回以上ある場合、4回目以降は「多数回該当」となり、自己負担限度額が軽減されます。

ただし、保険者が変わった場合や、70～74歳の外来のみの高額療養費など、通算の対象とならないケースがあります。

本ツールは判定を補助する目的のものであり、実際の多数回該当の可否は加入している医療保険者の判定が優先されます。

## ファイル構成

- `index.html`：アプリ本体
- `style.css`：画面デザイン
- `app.js`：判定ロジック
- `manifest.json`：PWA設定
- `service-worker.js`：オフラインキャッシュ

## 利用方法

GitHub Pagesなどの静的ホスティングに配置し、スマートフォン・PCのブラウザから利用できます。

PWAとしてホーム画面に追加することで、通常のアプリに近い操作で利用できます。

## 注意事項

本ツールは医療保険制度上の判定を補助するための参考ツールです。制度改正、加入する保険者、所得区分、年齢、該当月の取扱いなどによって判定が異なる場合があります。

実際の自己負担限度額および多数回該当の適用については、加入している健康保険組合、協会けんぽ、市区町村等へ確認してください。
